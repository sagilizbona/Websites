# הסדנה של אמיתי – אתר למוצרי הדפסת תלת־ממד

אתר חנות פשוט בעברית (RTL). HTML/CSS/JS בלבד – בלי שרת, בלי התקנות.
הלקוחות רואים את המוצרים (תמונות/סרטונים, שם, מחיר) ומזמינים בלחיצה דרך וואטסאפ.

| קובץ | מה זה |
|---|---|
| `index.html` | החנות עצמה |
| `admin.html` | עמוד ניהול – הוספה/עריכה/מחיקה של מוצרים, העלאת תמונות וסרטונים |
| `config.js` | **שם החנות, מספר וואטסאפ, מייל** – הקובץ היחיד שעורכים ידנית |
| `products.js` | רשימת המוצרים (מתעדכן אוטומטית מעמוד הניהול) |
| `media/` | התמונות והסרטונים של המוצרים |
| `assets/` | עיצוב וקוד |

## 1. הגדרה ראשונית

ב־`config.js` משנים את:
- `shopName` – שם החנות
- `whatsapp` – המספר שאליו יגיעו ההזמנות, בפורמט `9725XXXXXXXX` (בלי 0 בהתחלה, בלי מקפים)

## 2. העלאה לאוויר (GitHub Pages – חינם)

1. בריפו `websites` ב-GitHub: **Settings → Pages**
2. ב-**Source** בוחרים `Deploy from a branch`, ענף `main`, תיקייה `/ (root)` → Save
3. אחרי דקה–שתיים החנות תהיה זמינה בכתובת: `https://sagilizbona.github.io/websites/amitai/`

> GitHub Pages בחינם עובד רק על ריפו ציבורי (או בחשבון בתשלום).

## 3. הוספת מוצרים מהטלפון או מהמחשב

נכנסים ל־`admin.html` באתר (יש קישור "ניהול" בתחתית החנות).

**חיבור חד־פעמי – טוקן GitHub** (כדי ששמירה תעדכן את האתר ישירות):
1. ב-GitHub: **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
2. Repository access: **Only select repositories** → בוחרים את הריפו של האתר
3. Permissions → Repository permissions → **Contents: Read and write**
4. יוצרים, מעתיקים, ומדביקים בעמוד הניהול → "התחברות"

מעכשיו: ממלאים שם + מחיר + תיאור, מוסיפים תמונות/סרטונים, לוחצים **שמירה** – ותוך דקה–שתיים המוצר באתר.
אפשר גם לערוך, למחוק ולשנות סדר (▲▼).

**בלי טוקן?** עמוד הניהול עדיין עובד: מורידים ממנו את `products.js` ואת הקבצים החדשים, ומעלים אותם ידנית לריפו (`products.js` לתיקייה `amitai/`, הקבצים לתיקייה `amitai/media/`).

## טיפים
- תמונות גדולות מוקטנות אוטומטית לפני העלאה.
- סרטונים: קצרים (עד ~30 שניות) ובפורמט **MP4**. סרטוני `.mov` מאייפון לפעמים לא מתנגנים בכרום – באייפון אפשר לשנות ב-Settings → Camera → Formats → **Most Compatible**.
- סרטונים מתנגנים אוטומטית בלי קול, בלופ.
- התמונה/הסרטון הראשון של כל מוצר הוא מה שרואים קודם.
